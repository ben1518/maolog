# 原型演示视频脚本与拍摄清单（3 分钟内）

## 一、硬性技术参数核查（务必严格对齐简章第五条）

- **总时长**：严格控制在 **2 分 30 秒 — 2 分 55 秒**（主题一原型演示视频上限 **3 分钟**）。
- **画幅与分辨率**：全程统一横屏 `16:9`（**1920×1080**），禁止横竖混剪。
- **帧率与码率**：`30 fps`（逐行扫描），MP4（H.264）导出，码率 ≥ `8 Mbps`，体积 ≤ `500 MB`。
- **字幕与音频**：人声解说清晰、背景音乐音量压低（-20 dB 以下），全程配**简体中文字幕**。
- **片头片尾与水印**：
  - **片头（3 秒）**：作品名称《楚师智学——基于屏幕感知与 MobileClaw 的主动式 AI 个人学业管理平台》＋ 主题一「AI 赋能校园」；
  - **片尾（4 秒）**：主创姓名、计算机与智能技术学院、指导教师（如有）、所用 AI 工具清单（中国移动 MobileClaw、视觉大模型等）；
  - **零水印禁区**：剪映 / OBS / 录屏工具导出时关闭一切默认角标与片尾水印（带第三方水印属一票否决项）。

## 三、录屏前快速准备命令

若需要干净、丰富的演示看板数据（不影响你个人真实 `data/activity.db`），可点击主界面或直接运行：

```powershell
# 生成隔离的 v2 演示看板，或打开主界面的「演示看板」按钮直接录屏
.venv\Scripts\python.exe tools\seed_demo.py
```

（录屏后若用剪映剪辑：新建 1920×1080 工程 → 导出时分辨率选 `1080P`、帧率 `30fps`、码率调至 `推荐/较高`（确保 >8Mbps）、在「设置」中关闭「自动添加片尾水印」。）
