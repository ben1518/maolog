# 「楚师智学」功能扩展建议

> 面向「AI 赋能校园」主题，在一期屏幕感知引擎的基础上，还能加什么与学校真正相关的功能。
> 结论均标注了复用成本（S / M / L）与优先级（✅ 建议本期做 / ⏳ 二期 / ⚠️ 慎做）。

---

## 一、结论先行

**你现在缺的不是更多功能，是"学校"这个角色。**

一期做得很扎实，但它是一个**学生自查工具**：学生装在自己电脑上，自己看自己的时间轴。放到「AI 赋能校园」的评审桌上，评委一定会问一句：

> 「这个东西，学校拿它干什么？」

方案里现在的回答是模糊的（6.1 提到"与学工部门合作，仅提供聚合趋势"），一句话带过。而这一句，恰恰是"校园应用"和"个人效率工具"的分界线。

所以要加的不是零散功能，是**三个新角色**，共用同一条数据管道：

| 角色 | 拿到什么 | 用来干什么 |
|---|---|---|
| 学生（本人） | 完整明细 + 原始截图 | 自知、复盘、攒材料 |
| 教师 / 辅导员 | **只有匿名聚合** | 学风研判、教学反馈、风险早发现 |
| 学校（教务 / 学工） | 报告与趋势 | 决策依据、质量评估 |

再加一条**本校专属**的主线：楚雄师范学院是师范院校，而方案通篇八千字没出现"师范"两个字——这是目前最大的浪费（详见第五节）。

---

## 二、外部对标：别人在做什么，空位在哪

我查了近两年公开报道的落地案例，大致分三类玩家：

| 类型 | 代表 | 做法 | 数据从哪来 |
|---|---|---|---|
| AI 辅导员 / 办事大厅 | 四川大学「大川智问」（171 项校务、12 个部门、0.1 秒意图识别）、杭电「AI 辅导员 2.0」、湖南多校 | 问答 + 办事 + 数字人 | 学校制度文件、业务系统 |
| 学业预警 | 山东建筑大学「AI 学业管家」（预警 3880 人、辅导员干预覆盖 100%、近五年首次不毕业人数比 2019 年降 53%） | 成绩 + 出勤 + 消费多维预警 | 教务、一卡通、门禁 |
| 第二课堂 | 到梦空间（团中央指导，覆盖数千所高校）、潍坊理工「团小慧」（精准推送后报名转化率提升近一倍） | 活动报名 + 学分记账 + 画像推荐 | 学生报名与签到 |

**这三个方向都已经很挤，而且都不缺你。**

- 做问答机器人，你打不过有全校知识库和业务接口的学校信息中心；
- 做成绩预警，你拿不到教务数据，做出来是空壳；
- 做二课学分，到梦空间已经铺到几千所学校。

**空位在第四类：谁掌握"学习过程"本身的数据？**

上面三类玩家的输入都是"结果数据"或"人填的数据"——成绩、签到、报名、提问。**没有一个人知道学生昨天晚上八点到十点到底在干什么。** 而这正是你一期已经跑通的东西。

所以定位建议改成一句话：

> **别人做"校园大脑"，你做"校园的感觉神经"。**
> 不抢问答、不抢办事，只提供一件别人没有的东西：**可回溯的学习过程证据**。

这个定位一改，后面所有功能都有了归处——它们都是"这份证据还能给谁用"。

## 三、学生端：把"记录"变成"资产"（3 个）

### 3.1 学习成果自动归档 ✅ M

**解决什么**：学生最痛的不是"不知道自己学了多久"，是**"要交材料的时候凑不出来"**——评奖学金要写"本学年学习情况"，申请大创要写"项目经历"，找实习要写"掌握了什么"。真到那时候，全靠回忆瞎编。

**怎么做**：

- 从行为时间轴里抽取"可归档事件"：连续 3 天以上在写同一个项目 → 生成一条"项目经历（含起止时间、累计投入、技术栈关键词）"；连续多日看网课 + 做笔记 → 生成"在线课程学习记录"。
- 每条记录**先给学生看，学生点确认才进档案**（不做自动上报）。
- 一键导出三种格式：第二课堂佐证材料（PDF，含时间与截图脱敏缩略图）、简历项目段落（文字）、评奖申报表素材（结构化字段）。

**为什么这是最该先做的一个**：它是唯一一个**直接给学生省钱省事**的功能，也是留存动机最强的一个。现在的留存靠"第一次看到时间轴的哇 moment"，那个 moment 只能撑三天；而"期末要交材料"是每学期都会回来的硬需求。

**和学校的关系**：直接对接第二课堂学分认定、评奖评优、就业推荐三套业务，但**接口是导出文件，不是数据上传**——不碰学校系统，也不需要授权，落地门槛几乎为零。

---

### 3.2 专注力体检 + 全校匿名基线 ✅ S

**解决什么**：现在的看板告诉你"今天工作 4 小时"，但没告诉你**这算好还是差**。人对绝对数字没有感觉，对"你在同年级排 62%"才有感觉。

**怎么做**：

- 统计三个指标：**最长连续专注时长**、**日均深度工作段数（≥25 分钟不切换）**、**娱乐时段分布**（是否集中在深夜/上午黄金段）。
- 与匿名基线对比：同年级 / 同学院 / 全校三分位。基线只上传**统计量**（一个数字），不上传任何行为明细。
- 每周给一张"专注力体检卡"：三项指标 + 一句结论 + 一个可执行动作（例："你的黄金专注段是 9:30–11:00，但这周有 3 天在这个时段刷视频"）。

**为什么有价值**：把"我好像有点摆烂"这种模糊焦虑，变成"我在同年级后 30%，但我的黄金时段利用率其实不差"这种可判断的结论。这是**心理安慰 + 行为抓手**，比单纯的时间统计更有用。

---

### 3.3 课表驱动的场景理解 ✅ S

**解决什么**：现在系统知道你"在看视频"，但不知道**这个时间该不该看**。

**怎么做**：

- 录入课表（手动导入 CSV 或截图识别，一期不做教务对接）。
- 三个规则：上课时段检测到游戏/视频 → 温和提示；无课时段检测到"网课学习" → 记入学业投入；晚间 23:30 后仍有活动 → 次日早课提醒。
- 关键设计：**提示只走托盘气泡，不弹窗、不打断**。这一点要在方案里写明——它决定了产品是"教练"还是"监工"。

**为什么值得做**：成本极低，但让整个系统从"通用计时器"变成"懂校园作息的东西"。评审看到"它知道我今天上午一二节有课"，会立刻理解这东西是给学校做的。

## 四、教师 / 辅导员端：只给聚合，不给明细（3 个）

> **这一节有一条红线，先写在最前面：教师端永远看不到任何一个学生的明细、截图、窗口标题。**
> 只输出"班级 N 人的聚合曲线"和"风险等级"。这不是技术限制，是方案能不能被学校放心推广的前提。

### 4.1 班级学情温度计 ✅ M

**解决什么**：辅导员开班会讲学风，手里只有"上学期挂科率"这种滞后半年的数据，说不出"你们这周晚上在干什么"。

**怎么做**：

- 班级维度四个指标：**周均学习时长中位数**、**深夜活跃比例**（23:30 后仍有屏幕活动的人数占比）、**娱乐时长占比中位数**、**学习时段规律性**（每天开始学习时间的标准差）。
- 呈现为一条班级趋势曲线 + 全院对比，**不出现任何学生姓名**。人数少于 8 人的班级不出报表（防止反推个人）。
- 配套：给辅导员的"班会素材包"——三条数据 + 一句建议话术。

**边界**：默认关闭，需班级学生**集体授权率 ≥ 80%** 才开启；任何学生可随时退出，退出后不计入分母。

---

### 4.2 课程投入度反馈 ⏳ M

**解决什么**：现在的教学评价是期末一次性打分，学生凭印象，教师拿不到过程反馈。而"这门课学生课外到底投入了多少"是个真问题——投入过低可能是作业设计有问题，也可能是学生放弃了。

**怎么做**：

- 教师发布课程时填一个"建议课外投入"（例：每周 2 小时）。
- 学期中给教师一份**匿名分布**：本课程学生课外投入的中位数、四分位、随时间的变化曲线。
- 教师端**看不到谁没投入**，只能看到分布。想找具体学生，走正常谈心流程。

**为什么学校会喜欢**：这是审核评估、一流课程建设里"过程性评价"的真实材料，而且不增加学生任何填表负担。

---

### 4.3 风险信号接口 ⚠️ L（做接口，不做系统）

**解决什么**：山东建筑大学的案例说明，行为预警是学校最愿意买单的功能（3880 人预警、干预覆盖 100%）。但它也是最容易踩红线的。

**建议做法（保守版）**：

- 不做独立预警系统，只做**一个信号输出接口**：连续 5 天学习时长低于本人基线 50%、连续 7 天无任何学习类活动、昼夜节律急剧后移 → 输出"关注等级 1/2/3"。
- 对接学校已有的学业预警 / 心理预警流程，**不新建流程、不建学生画像、不做排名**。
- 学生本人**先于辅导员**收到提示，并且可以看到"系统为什么这么判断"（哪几天、什么数据）。
- 一切以"学生知情"为前提。

**为什么标⚠️**：这个功能写进方案能加分（体现"科学决策"），但做进产品要非常克制。建议方案里写成"三期试点，需学工部门共同制定规则"，而不是承诺功能。

---

## 五、师范院校专属：这是你最该抓住的差异化（3 个）

楚雄师范学院的核心业务是**培养老师**。而师范生有三个别处没有的刚需，恰好全都能复用你已有的"录屏 + 视觉理解 + 资料提炼"能力：

### 5.1 试讲 AI 教练 ✅ M

**场景**：师范生每学期都要试讲、微格教学、教资面试模拟。现在是同学互评——互相给面子，说不出一句有用的。

**怎么做**：

- 学生用电脑摄像头录一段 10 分钟试讲（或直接录屏 + 摄像头画中画）。
- 模型输出四维评分 + 具体证据：
  - **语言**：语速（字/分钟）、口头禅频次（"那个""然后"）、停顿分布；
  - **教态**：是否长期低头看稿、是否面对镜头、手势幅度；
  - **结构**：导入 / 讲解 / 提问 / 小结四段是否齐全，各占多久；
  - **互动**：提问次数、等待回答的秒数（很多师范生问完立刻自己答了）。
- 输出不是"85 分"，而是**带时间码的问题清单**："03:12 提问后只等了 1.2 秒就自答，建议留 5 秒"。

**为什么这是王牌**：评委是本校老师，看到"这东西能用来带师范生"会立刻有共鸣；而且它跟屏幕感知同源（都是"看画面 + 给结构化判断"），技术上不是新摊子，是同一套能力的换场景复用。**一个能力，两个场景，这是方案里最漂亮的叙事。**

---

### 5.2 教资 / 普通话备考包 ⏳ S

**做法**：直接把二期的 `material-digest` 拿来用，只是知识库换成教资三科 + 普通话 + 三笔字规范。产出照旧四件套：导图、速记卡、模拟题、考前清单。

**为什么单列**：它是**唯一一个全校所有专业都要用的功能**（不分年级、不分学院），推广面比"专业课资料提炼"大得多。用它做二期的最小验证场景，比做《数据结构》更有说服力。

---

### 5.3 教育实习 / 顶岗支教支持 ⏳ M

**场景**：师范生大四要去乡镇学校顶岗实习，网络差、指导老师远、周报靠编。

**怎么做**：

- **离线优先**（你的本地架构天生适合）：实习点没网也能记录、也能本地分析，回到有网环境再同步摘要。
- **实习周报自动生成**：从备课、写教案、做课件的行为记录 + 课堂录像片段，生成"本周工作 + 遇到的问题 + 下周计划"的草稿，学生改两句就能交。
- **远程教研**：把课堂录像的关键片段（提问、板书、纪律处理）截出来，附 AI 观察，发给校内指导老师，代替"一学期来一次"的现场指导。

**为什么有价值**：这一段直接对上"服务地方基础教育"的办学定位，是方案结尾最容易被记住的一段话。

## 六、如果只加三个

时间有限的话，按这个顺序：

| 顺序 | 功能 | 补的是什么短板 |
|---|---|---|
| 1 | **学习成果自动归档** | 学生为什么天天开它——从"好奇"变成"要用" |
| 2 | **班级学情温度计** | 学校拿它干什么——从"个人工具"变成"校园应用" |
| 3 | **试讲 AI 教练** | 凭什么在师范院校做——从"通用产品"变成"本校方案" |

这三个加起来，方案的故事就完整了：**学生愿意用 → 老师有得看 → 学校愿意推 → 还是本校特色。**

## 七、对上评审维度

公开的 AI+ 教育类赛事评审口径大致是五个维度（以你们赛事手册为准）。现有方案与新增功能的对位：

| 维度 | 现在靠什么拿分 | 加了什么之后更稳 |
|---|---|---|
| 场景适配性 | 三个校园痛点 | 师范生试讲、教资、实习支教——**本校场景越具体越高分** |
| 技术规范性 | 四层架构、四道隐私闸门、54 项测试 | 增加"聚合输出"的数据脱敏设计、匿名基线的最小上传原则 |
| 创新优化性 | 屏幕语义理解 + 行为与目标打通 | "一个感知引擎，两个场景"（学习复盘 / 试讲分析）|
| 实施显著性 | 一期已真实运行 | 试点方案：30–50 人 + 留存率 + 一份校级行为报告 |
| 推广适配性 | 规则外置、Skills 标准化 | 教师端只依赖聚合数据，其他学校接入零改造 |

## 八、和中国移动生态怎么结合（加分项，别硬凑）

公开报道里的现成抓手：

- **MClaw / 灵犀智能体**：你的四个 Skill 可以直接以 MClaw 技能包形态上架，学校按需启用；
- **动感地带芒果卡**：湖北高校的开学季方案里，入门档就是"移动云盘 + 灵犀 + MClaw"，配每月千万级 Token 与 4T 云空间——你的视觉识别是持续消耗型任务，**这正好是"算力从哪来"的答案**；
- **云电脑 / 云 PAD**：机房、实验室场景可以零安装跑起来，解决"学生电脑装不了"的推广障碍；
- **微信推送**：日终总结、周报推到微信，是留存的关键一环（现在的托盘通知容易被忽略）。

写法上注意：**别写成"我们用了移动的云"**，要写成"我们的架构天生适配按量算力 + 本地隐私，与移动的算力进校园是同一套逻辑"。

## 九、不建议做的四件事

| 不做 | 原因 |
|---|---|
| 通用 AI 辅导员 / 校园百事通 | 红海，且必须依赖全校制度知识库与业务接口，学生团队拿不到 |
| 课堂人脸识别 / 抬头率 | 伦理风险极高，硬件依赖强，且与"隐私优先"的立身之本自相矛盾 |
| 手机端监控 | 越界。电脑屏幕是"学习工具"，手机是"私人领域"，一旦跨过去，方案就变成监控软件 |
| 教师查看个体明细 | 一旦开口子，前面所有隐私设计全部作废，学校也不敢推广 |

## 十、落地方式（不动主入口）

按你一贯的习惯，新功能全部隔离，不改 `main.py` 的装配逻辑：

```
core/
├── archive.py          # 3.1 成果归档：从 segments 抽取可归档事件
├── baseline.py         # 3.2 匿名基线：本地统计 → 只上传聚合量
├── schedule.py         # 3.3 课表：CSV 导入 + 时段规则
└── aggregate.py        # 4.1/4.2 班级聚合：k-匿名，N<8 不出报表
skills/
├── teach_review/       # 5.1 试讲分析：视频 → 四维评分 → 时间码问题清单
└── archive_export/     # 3.1 导出：PDF / 简历段落 / 申报表字段
ui/
├── archive_page.py     # 新增"档案"页
└── class_view.py       # 班级视图（只读聚合）
```

数据层只**新增表**，不改现有 `snapshots` / `daily_summaries`：

- `archive_events`（可归档事件）
- `course_schedule`（课表）
- `aggregate_snapshots`（匿名聚合，无学生标识）

## 附：可直接粘进方案说明书的三段

### 2.5【规划中】学习成果自动归档

平台把行为时间轴从"复盘工具"推进为"资产生产线"：连续多日围绕同一项目的操作，会被归纳为一条带起止时间与投入时长的项目经历；一段时间的网课学习与笔记行为，会被归纳为课程学习记录。所有条目须经学生本人确认后方可入档，可一键导出为第二课堂佐证材料、简历项目段落与评奖申报素材。**平台不向任何系统自动上报，导出动作始终由学生发起。**

### 2.6【规划中】班级学情聚合视图（教师端）

在不暴露任何个体明细的前提下，平台向辅导员与任课教师提供班级维度的聚合视图：周均学习时长中位数、深夜活跃比例、娱乐时长占比、学习时段规律性。视图设置三重约束：仅显示聚合统计量、班级人数少于 8 人不生成报表、需班级学生集体授权率达 80% 方可开启。其价值不在于"监控"，而在于让学风建设与教学反馈第一次拥有**过程性证据**。

### 2.7【规划中】师范生教学技能 AI 教练

面向师范生试讲、微格教学与教师资格证面试场景，平台复用同一套视觉理解能力，对试讲录像进行四维分析：语言（语速、口头禅、停顿）、教态（视线、手势、看稿时长）、结构（导入/讲解/提问/小结的时长配比）、互动（提问次数与等待时长）。输出不是分数，而是**带时间码的具体问题清单**，使"同学互评"升级为"有证据的自评"。这一模块与屏幕感知共用同一套感知与结构化输出能力，是"一个引擎、两个场景"的直接体现。
